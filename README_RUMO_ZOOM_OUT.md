# Atualização visual Rumo com zoom out

Aplicado o mesmo padrão visual Rumo usado nos demais sistemas de qualidade, com redução de escala para exibir mais conteúdo na tela.

## Alterações principais

- Tema claro Rumo como padrão, com opção de tema escuro preservada.
- Logo e favicon Rumo adicionados em `assets/brand`.
- Topbar, hero, área de upload, abas, KPIs, painéis, filtros e tabelas compactados.
- Menores fontes, paddings, alturas, espaçamentos e cards para efeito de zoom out visual.
- Dashboard reorganizado para leitura mais rápida e menos rolagem.
- Cache bust aplicado em `index.html` para GitHub Pages atualizar CSS/JS.

## Importante

A lógica de leitura do PDF, processamento da planilha e cruzamento de dados foi preservada.
